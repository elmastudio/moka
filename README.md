# Moka

Moka is a responsive, minimal blog, magazine and creative business theme with a beautiful, modern design and lots of easy-to-use, individual theme features like a customizable front page template, an about and quote template and a sticky sidebar option.

By [Elmastudio](https://www.elmastudio.de/en/).

- **Version:** 1.1.10
- **Theme page:** https://www.elmastudio.de/en/wordpress-themes/moka/
- **Documentation:** [English](https://www.elmastudio.de/en/docs/moka/) / [German](https://www.elmastudio.de/doks/moka/)

## Installation

Download this repository as a ZIP and upload it in **Appearance → Themes → Add New → Upload Theme**, or clone it into your WordPress installation:

```
cd wp-content/themes
git clone https://github.com/elmastudio/moka.git
```

## Status

This theme is no longer actively developed. It is published here as-is, for anyone who still runs it or wants to build on it.
